# 🍷 Vinharia Agnello

## Sobre o projeto

A Vinharia Agnello é um projeto desenvolvido para apresentar uma experiência relacionada ao universo dos vinhos.

O site apresenta a história da Vinharia, diferentes tipos de vinhos, experiências de degustação e uma área de contato para solicitação de visitas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Páginas do projeto

- Início
- História
- Vinhos
- Experiências
- Contato

## Funcionalidades

- Menu de navegação entre as páginas
- Imagens e vídeo
- Lista de experiências
- Tabela de vinhos
- Área de contato
- Layout responsivo
- Links internos e externos
- Interação com o usuário utilizando JavaScript
- Cadastro e processamento de informações sobre vinhos
- Validação dos dados informados
- Análise das informações cadastradas
- Identificação de vinhos com estoque baixo
- Identificação da safra mais antiga
- Exibição de um resumo dos dados processados

## Objetivo

O objetivo do projeto é aplicar conhecimentos de desenvolvimento web utilizando HTML5, CSS3 e JavaScript, trabalhando estrutura semântica, navegação, tabelas, imagens, vídeos, estilização, lógica de programação e interação com o usuário.

## Efeitos Visuais

O projeto utiliza CSS para deixar a navegação mais interativa e agradável. Foram aplicados:

- **Pseudo-classes:** efeitos ao passar o mouse nos links, foco nos elementos interativos e destaque nas linhas da tabela.
- **Pseudo-elementos:** detalhes decorativos nos títulos.
- **Animações:** entrada suave do conteúdo da página.
- **Transições:** mudanças suaves nos links e botões.
- **Transformações:** movimentos e efeitos nas imagens e nos botões.

## JavaScript

Nesta etapa do projeto, foram aplicados conceitos fundamentais de JavaScript para trabalhar a lógica de programação e o processamento de informações sobre vinhos.

- **Variáveis:** armazenamento de dados.
- **Funções:** organização e reutilização do código.
- **Estruturas condicionais:** verificação de informações.
- **Estruturas de repetição:** processamento de múltiplos cadastros.
- **Entrada e saída de dados:** interação com o usuário utilizando `prompt()` e `alert()`.
- **Validação de dados:** verificação das informações fornecidas.
- **Análise de estoque:** identificação de vinhos com estoque baixo.
- **Análise de safra:** identificação da safra mais antiga cadastrada.
- **Resumo final:** apresentação dos resultados do processamento.

O objetivo dessa etapa é aplicar os conhecimentos de JavaScript na prática, ampliando a lógica e as funcionalidades do projeto.
